# Electro House v1

This style pack describes reusable musical roles and section defaults. It does
not contain samples, melodies, chord progressions, synth presets, or audio.

The pack favors four-on-the-floor drums, offbeat root bass, rhythmic triads,
and a motif-driven lead. A song supplies its own pitch identity, form, energy
curves, and transformations. Production software may map each role to any
instrument without altering the source DNA.

## Roles

- `kick`, `clap`, `closed_hat`, `open_hat`, `percussion`: General MIDI drum triggers.
- `bass`: Chord-root pulses.
- `harmony`: Diatonic triads derived from the song progression.
- `lead`: Repetition and transformation of the song's original motif.
- `fx_trigger`: A placeholder MIDI trigger for original transition sound design.
